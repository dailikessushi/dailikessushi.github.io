= Vulkan日本

== Vulkanとは？

Vulkanとは、 https://www.khronos.org/[クロノス・グループ]によって定められた、クロスプラットホームの低レベルグラフィックスと計算を明示的に制御するために設計された http://www.open-std.org/jtc1/sc22/wg14/www/standards[C99] API(アプリケーションプログラミングインターフェース)です。
